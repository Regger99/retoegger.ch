# retoegger.ch

Webseite von Reto Egger, Orientierungsläufer.

- `index.html` und `assets/`: Gestaltung der Seite
- `inhalte/`: News, Bilder, Kalender und Resultate (siehe [ANLEITUNG.md](ANLEITUNG.md))
- `werkzeuge/build.py`: baut daraus die fertige Seite
- `.github/workflows/webseite.yml`: veröffentlicht die Seite bei jeder Änderung automatisch über GitHub Pages
